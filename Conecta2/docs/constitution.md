# Constitución del Proyecto: Conecta2

## 1. Accesibilidad Extrema
- **Regla 1:** La interfaz debe ser para personas mayores (fuentes grandes, botones gigantes, alto contraste).
- **Regla 2:** Flujos simples y guiados. Un botón principal por pantalla.
- **Regla 3:** Priorizar la interacción por voz (Speech-to-Text).

## 2. Privacidad y Seguridad
- **Regla 4:** No pedir ni guardar datos personales sensibles (ubicación exacta, apellidos reales).
- **Regla 5:** Doble confirmación en acciones críticas (ej. colgar llamada).

## 3. Calidad y Arquitectura
- **Regla 6:** Backend (Flask) separado de Frontend (HTML/JS) vía API REST.
- **Regla 7:** Código legible y comentado, priorizando el funcionamiento del MVP sobre la optimización.

## 4. Uso de IA
- **Regla 8:** Todo código generado por IA debe ser revisado y aprobado por el equipo antes de integrarse.
